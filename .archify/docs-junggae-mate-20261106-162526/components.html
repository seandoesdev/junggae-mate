중개메이트의 각 구성 요소는 무엇을 하나요?

Long image

A

Answer

중개메이트는 Cloudflare Pages의 React 화면과 nginx 뒤의 FastAPI 서버 하나로 동작하고, 모든 자료는 사무소별로 나뉜 PostgreSQL 하나에 저장됩니다.

  1. 화면은 서버 주소를 config.json에서 받아, 서버 주소가 바뀌어도 다시 빌드하지 않습니다.1
  2. 서버는 443 포트만 공개하고, nginx가 TLS를 풀어 FastAPI로 넘깁니다.2
  3. Hood AI는 매물·공공데이터(SQL)와 문서(검색)를 근거로 묶어 답하고, 근거가 부족하면 단정하지 않습니다.3

요청은 어떤 순서로 지나가나요?

Diagram structure

  • nginx 443 nginx
  • FastAPI fastapi
  • Hood AI hood
  • 거래·보고서 workflow
  • 공공데이터 수집 collector
  • PostgreSQL db
  • pages → nginx · /api 요청
  • nginx → fastapi · 8000 프록시
  • fastapi → hood · 질문
  • fastapi → workflow · 업무
  • fastapi → collector · 관리자
  • hood → db · 근거 조회
  • workflow → db · 저장
  • collector → db · upsert
  1. React 화면 ↗

    Cloudflare Pages가 화면 파일을 내려 주고, 화면은 config.json에서 서버 주소를 받습니다.

  2. nginx 443 ↗

    서버로 오는 모든 연결을 받아 TLS를 풀고 FastAPI로 넘깁니다.

  3. FastAPI ↗

    로그인 토큰을 확인하고, 요청을 사무소 범위로 좁혀 각 기능에 넘깁니다.

  4. PostgreSQL ↗

    업무 자료, 공공데이터, 문서 조각과 벡터를 함께 저장합니다.

서버 앞단은 무엇을 맡나요?

구성 요소하는 일위치
nginx 443TLS를 풀지 않고 ALPN만 먼저 봅니다. acme-tls/1 연결은 acme로, 나머지는 내부 8443에서 TLS를 풀어 app:8000으로 넘깁니다.deploy/nginx/nginx.conf
nginx 80인증서 확인 파일만 내려 주고, 나머지 요청은 https로 돌립니다.deploy/nginx/nginx.conf
acme.shLet's Encrypt에서 인증서를 받고 갱신합니다. 서버 주소가 IP면 약 6일짜리 단기 인증서를 받습니다. 인증서가 바뀌면 nginx가 1분 안에 다시 읽습니다.deploy/acme/entrypoint.sh
Let's Encrypt인증서를 발급하는 기관입니다. 443으로 들어온 확인 요청(TLS-ALPN-01)으로 서버 소유를 확인합니다.외부

인증서 처리 순서는 acme 스크립트에 있습니다.5

백엔드 모듈은 각각 무엇을 하나요?

구성 요소하는 일위치
FastAPI (main.py)허용한 화면 주소만 CORS로 받고, 요청마다 ID를 붙이고, /api 라우터를 연결합니다.backend/app/main.py
API 라우터 (api.py)59개 API의 입력을 검사하고, 로그인 사용자의 사무소 자료만 다루게 합니다.backend/app/api.py
보안 (security.py)비밀번호를 PBKDF2로 저장하고, JWT(HS256) 토큰을 만들고 확인합니다. 관리자 전용 API를 가립니다.backend/app/security.py
Hood AI 대화 (hood.py)월 질문 한도를 확인하고, "그중 7억 이하만" 같은 이어 묻기를 앞 질문과 합칩니다. 대화와 검색 추적을 저장합니다.backend/app/hood.py
답변 조립 (assistant.py)질문에서 지역·가격·면적·역을 뽑고, 매물·실거래·공공데이터·문서 중 필요한 경로만 골라 답변을 만듭니다.backend/app/assistant.py
구조화 근거 (structured.py)매물을 K-apt 단지, 건축물대장, 지하철역과 연결하고, 연결된 공공데이터를 근거로 돌려줍니다. 연결 확정은 사람이 합니다.backend/app/structured.py
문서 검색 (rag.py)문서를 조각내 저장하고, 벡터와 키워드 점수로 찾고, 근거 게이트로 부족·충돌·시행 전을 판정합니다.backend/app/rag.py
초안 작성 (drafting.py)근거 번호가 붙은 문장과 확인할 사항을 만들고, LLM 문장의 출처를 검증합니다.backend/app/drafting.py
Claude 연결 (llm.py)API 키가 있을 때만 근거를 문장으로 다듬습니다. 키가 없으면 규칙 기반 문장으로 답합니다.backend/app/llm.py
거래·보고서 (workflow.py)거래 단계(소개→방문→협상→계약→완료), 체크리스트, 보고서 검토·승인·공유 링크를 다룹니다.backend/app/workflow.py
공공데이터 수집 (public_data.py, public_sources.py)공공데이터포털 API를 부르고, 응답을 정규화해 같은 키는 덮어쓰기(upsert)로 저장합니다.backend/app/public_sources.py
감사 기록 (audit.py)문서 등록, 단계 변경, 승인 같은 중요한 변경을 남깁니다. 관리자만 봅니다.backend/app/audit.py

핵심 흐름은 대화6, 답변 조립3, 구조화 근거7, 문서 검색8, 거래 단계9입니다.

데이터와 외부 서비스는 무엇을 맡나요?

구성 요소하는 일위치
PostgreSQL 16사무소, 사용자, 매물, 고객, 거래, 보고서, 대화를 저장합니다. 모든 업무 표에 tenant_id가 있어 사무소별로 나뉩니다.backend/sql/schema.sql
